# Hatsune Miku Theme

> "The World is My Stage, and Code is My Song."

A VS Code dark theme inspired by Hatsune Miku, optimized for long coding sessions.

## Features

- **APCA-compliant contrast** for comfortable 8+ hour sessions
- **Character-semantic colors** - Miku's design mapped to syntax
- **Cyber-Diva UI** - Holographic notifications, data stream status bar
- **24 languages** with dedicated syntax highlighting

## Supported Languages

TypeScript, JavaScript, TSX, HTML, CSS, SCSS, JSON, Rust, Go, C, C++, Java, C#, Python, Ruby, PHP, SQL, YAML, XML, Dockerfile, Shell, Makefile, Markdown

## Install

1. Open VS Code Extensions (`Ctrl+Shift+X`)
2. Search **"Hatsune Miku Theme"**
3. Click **Install**
4. `Ctrl+K` then `Ctrl+T` → Select **Hatsune Miku Theme**

## Development

```bash
npm install
npm run build
npm run check-readability
```
